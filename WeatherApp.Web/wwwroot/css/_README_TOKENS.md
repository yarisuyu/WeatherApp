Файл tokens.css содержит семантические CSS‑переменные для темы приложения.

Рекомендации:
- Меняйте значения в tokens.css для переопределения тем (например .theme-dark).
- Не дублируйте цвета в component CSS; используйте var(--...).
- Для новых семантических токенов добавляйте имена в стиле --text-primary, --bg-surface и т.д.
